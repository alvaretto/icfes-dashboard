# Dashboard ICFES Saber 11° · I.E. Pedacito de Cielo

Análisis longitudinal de tres simulacros tipo Saber 11° (Fases I, II y III) aplicados por la Secretaría de Educación Departamental del Quindío entre febrero y abril de 2026.

**Ver dashboard:** [https://alvaretto.github.io/icfes-dashboard/](https://alvaretto.github.io/icfes-dashboard/)

## Contenido

- 10 secciones analíticas con gráficas interactivas (Chart.js)
- Análisis por grupo (11A, 11B, PENSAR 3A, 3B, 3C)
- Cohorte estable de 24 estudiantes con trayectoria longitudinal
- Identificación nominal de riesgo crítico y alto potencial
- 8 hallazgos con recomendaciones data-driven

## Tecnología

Archivo HTML autocontenido (~89KB). Solo requiere conexión a internet para cargar fuentes (Google Fonts) y Chart.js (cdnjs).
